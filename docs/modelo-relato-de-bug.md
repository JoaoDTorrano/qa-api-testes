# Modelo de relato de bug

Copie este modelo para um arquivo novo em `docs/bugs/` (por exemplo, `BUG-001-titulo-curto.md`) a cada defeito encontrado.

```markdown
# BUG-000: título curto que descreve o problema

| Campo | Valor |
|---|---|
| Data | AAAA-MM-DD |
| Severidade | Crítica, alta, média ou baixa |
| Ambiente | URL, versão, navegador ou ferramenta |
| Caso de teste | ID do caso relacionado |

## Passos para reproduzir

1. Primeiro passo
2. Segundo passo

## Resultado esperado

O que deveria acontecer e onde isso está definido (requisito, documentação ou critério de aceite).

## Resultado obtido

O que aconteceu de fato.

## Evidências

Resposta da API, captura de tela ou log.

## Observações

Frequência (sempre ou às vezes), contornos possíveis e dúvidas em aberto.
```
